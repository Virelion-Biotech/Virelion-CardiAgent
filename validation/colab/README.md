# Colab CVAE Scientific Validation

`validation_colab.py` is the current scientific-validation harness for the CardiAgent conditional VAE generator.

## What changed from the original diagnostic

The original run trained and evaluated against the same 700 generated examples. That was useful as an execution check but was insufficient for generative generalization.

The current harness instead uses:

- 60% train / 20% validation / 20% held-out test
- stratification by challenge domain and requested severity
- exact domain/severity matching between generated cases and held-out cases
- explicit handling of constant features without `nan_to_num` correlation masking
- bootstrap 95% CIs for feature mean differences
- KS and Wasserstein distribution comparisons
- variance-ratio / variance-collapse diagnostics
- multivariate correlation comparison with undefined pairs retained as undefined
- generated-to-train vs held-out-to-train nearest-neighbour novelty comparison
- duplicate-vector detection
- five-fold generated-vs-held-out logistic discriminator AUC
- same-seed reproducibility and multiple independent model seeds
- severity-response slope comparison
- predeclared screening targets recorded in the output

## Colab

After cloning and installing the repository, install the validation-only dependencies:

```bash
pip install -q scipy scikit-learn
```

Then run:

```bash
python validation/colab/validation_colab.py
```

The script writes `validation_colab_results_v2/` containing:

| File | Purpose |
|------|---------|
| `scientific_validation_report.json` | Complete numerical results and environment metadata |
| `scientific_validation_report.md` | Human-readable interpretation and screening result |
| `scientific_validation_summary.txt` | Compact run summary |
| `condition_metrics.csv` | Per-domain/per-severity metrics suitable for inspection or plotting |
| `split_manifest.json` | Reproducible train/validation/test ID split |

## Interpretation

This protocol validates internal computational generalization of the ML generator. It does **not** establish external biological validity because the source population is still generated by CardiAgent's deterministic challenge model rather than an independent biological cohort.

A failed screen is retained as a result. Thresholds must not be changed after observing the output and then used to claim a pass.

## Historical run

The earlier Colab artifacts in this directory are retained as a historical baseline. That run reported reproducibility, bounds, uniqueness, and trajectory checks as passing, but its ML evaluation used the training population itself and produced repeated zero-variance correlation warnings. Those results should not be treated as final generative validation.
